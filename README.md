# 1tap

Android WebView shell for the Solana dApp Store. Generated by the Solana Mobile CLI
(`solana-mobile webshell`), then patched.

## Configuration

- Web URL: `https://beta.1tap.trade/`
- Application ID: `trade.onetap`
- Version code: `1`
- Version name: `0.0.1`
- Kotlin package / namespace: `trade.onetap`

The application ID is permanent once published to the dApp Store.

## Changes from the template

- `MainActivity`: insets use `WindowInsets.safeDrawing`, so the page resizes above the
  keyboard (edge-to-edge disables the default resize).
- `MainActivity`: dark system bars with light icons.
- `MainActivity`: pull-to-refresh disabled; vertical drags on the canvas reloaded the page.
- `AndroidManifest.xml`: `VIBRATE` permission, required by `navigator.vibrate`.
- `ui/theme/Theme.kt`: fixed dark scheme, no dynamic color.

## Build

```bash
solana-mobile webshell build .
adb install -r app/build/outputs/apk/release/app-release.apk
```

## Release signing

The release keystore lives outside this repo and is never committed. The dApp Store
ties every update to the key that signed the first release, so losing it means a new
application ID.

Pass the path and alias as Gradle properties, and the passwords as environment
variables:

- `-PSOLANA_MOBILE_KEYSTORE_PATH=<path>`
- `-PSOLANA_MOBILE_KEYSTORE_ALIAS=<alias>`
- `SOLANA_MOBILE_KEYSTORE_PASSWORD`
- `SOLANA_MOBILE_KEY_PASSWORD`

## Notes

- This project is a WebView-based Android shell, not a Trusted Web Activity.
- The user agent ends with `Solana Mobile Web Shell`.
- External links outside the configured host open in the system browser.
- Solana wallet intents are handled natively by the app shell.
